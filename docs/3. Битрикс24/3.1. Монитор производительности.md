# Монитор производительности

[Содержание](../../README.md) · [MySQL](<../1. Сервер/1.3. MySQL.md>)

Административная часть → Настройки → Производительность. Названия пунктов зависят от версии.

| Раздел | Что смотреть |
| --- | --- |
| Панель производительности | Замечания к конфигурации PHP, БД и приложения |
| Страницы | Частота, среднее и суммарное время, количество и время SQL |
| Хиты | Конкретный медленный запрос и участвовавшие компоненты |
| Компоненты | Частые вызовы, суммарная стоимость, компоненты из `/local/components/` |
| SQL-запросы | Повторы, длительность, план, стек вызовов, если записан |
| Кеширование | Частые создания/удаления кеша, крупные записи |
| Ошибки PHP | Повторяющиеся ошибки модулей и обработчиков |

Приоритет: запросы, которые и дороги, и часто выполняются. Время SQL входит во время хита. Если SQL занимает малую долю, проверить внешние API, файловые операции и PHP-профиль.

## Сбор статистики

В настройках модуля «Монитор производительности» проверить, что уже собирается. Если данных нет, включить сбор на короткий согласованный период, воспроизвести сценарий, вернуть прежние настройки.

Полный SQL и стеки вызовов добавляют нагрузку и быстро увеличивают объём данных. Тест масштабируемости создаёт отдельную нагрузку; не запускать его на production при обычной диагностике.

Оценка в панели не измеряет готовность интерфейса. Её проверять в [браузере](<../2. Браузер/2.1. Frontend.md>).
