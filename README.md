# Производительность Битрикс24

Шпаргалка для диагностики коробочного Битрикс24 по SSH и в браузере.

[Порядок проверок](<docs/5. Рекоммендации/audit-workflow.md>) · [Что проверять](docs/scope.md)

[Шаблон отчёта](<docs/6. Отчет/report-template.md>) · [Пример заполнения на вымышленных данных](<docs/6. Отчет/report-example.md>)

Пути и имена служб в примерах преимущественно для BitrixVM/RHEL. SQL выполнять в БД портала, если не указано другое. Диагностика не требует сброса кешей или перезапуска служб; изменения конфигурации вынесены в раздел таймингов. Большие логи и обходы каталогов создают нагрузку. Логи, HAR и конфигурации с секретами в репозиторий не добавлять.
